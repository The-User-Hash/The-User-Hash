# 技术提案 PPT

> 本提案针对大模型推理场景下的显存成本问题，

> 已同步提交给深度求索（DeepSeek）与米哈游评估。

## 提案内容

- **问题背景**：长上下文推理中 KV Cache 显存占用过高
- **核心方案**：按访问频率分层，热数据留显存、冷数据下沉
- **预期收益**：显存占用下降，单卡可承载并发数提升
- **落地路径**：分三阶段推进，可先在推理服务侧灰度验证

完整 PPT 见本仓库 `提案PPT/` 目录。

- **移动端**：APP 开发、端侧模型部署
